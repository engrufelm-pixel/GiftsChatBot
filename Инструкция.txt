ИНСТРУКЦИЯ К ЧАТ-БОТУ GIFTS.RU

1. ЗАПУСК
- Установите Python 3.10+
- Выполните команду: pip install -r requirements.txt
- Запустите сервер: python app.py

2. БАЗА ТОВАРОВ
- Текущая база (36 335 позиций) загружена в catalog.xlsx.
- Для обновления базы используйте скрипт xml_to_excel.py (положите новый product.xml в папку и запустите скрипт).

3. НАСТРОЙКА ЦЕН
- В текущей выгрузке product.xml от клиента отсутствуют ценовые поля. 
- Для активации функции подбора по бюджету необходимо объединить текущий каталог с файлом цен (price.xml / stocks.xml). 
- Логика подбора в коде уже полностью настроена и активируется автоматически при появлении данных в колонке "Цена".

4. БАЗА ЗНАНИЙ
- Бот обучен по регламенту (PDF) и отвечает на 50+ корпоративных вопросов.
