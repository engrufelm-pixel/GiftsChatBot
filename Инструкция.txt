================================================================
ИНСТРУКЦИЯ К ЧАТ-БОТУ GIFTS.RU
================================================================

1. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ И ЗАПУСК
----------------------------------------------------------------
- Язык: Python 3.10 или выше.
- Установка зависимостей: введите в консоли команду:
  pip install -r requirements.txt
- Локальный запуск сервера: 
  python app.py
- Бот будет доступен в браузере по адресу: http://127.0.0.1:5000
- Для запуска на "боевом" сервере (продакшн) используйте Gunicorn:
  gunicorn app:app

2. НАСТРОЙКА НЕЙРОСЕТИ И API КЛЮЧЕЙ
----------------------------------------------------------------
Все секретные ключи хранятся в файле .env (скрытый файл в папке проекта).
Внутри файла прописаны настройки:
  OPENAI_API_KEY=ваш_ключ
  OPENAI_BASE_URL=ваш_url_если_используете_прокси
  OPENAI_MODEL=gpt-4o-mini

ВАЖНО: Сейчас в файле .env установлен демонстрационный ключ с балансом для тестов.
Стоимость одного сложного ответа ИИ по базе знаний составляет около 0.2 руб.
Когда тестовый баланс закончится, вам нужно будет зарегистрировать свой ключ OpenAI 
(или любого прокси-сервиса, работающего в РФ, например AITUNNEL) и заменить его в файле .env.

3. КАТАЛОГ ТОВАРОВ И ЦЕНЫ
----------------------------------------------------------------
Основа бота — файл catalog.xlsx (в текущей версии загружено более 36 000 товаров).
Чтобы обновить базу из официального XML-фида Gifts.ru:
1. Положите актуальный файл product.xml в папку с ботом.
2. Запустите скрипт: python xml_to_excel.py
3. Скрипт автоматически создаст новый catalog.xlsx с фото и артикулами.

ВНИМАНИЕ ПО ЦЕНАМ: 
В текущей выгрузке product.xml отсутствуют ценовые поля (только описания). 
Из-за этого бот временно не может делать подборки строго по бюджету. 
Для активации функции подборок необходимо выгрузить из кабинета дилера второй файл 
(price.xml / stocks.xml) и объединить цены с файлом catalog.xlsx. 
Логика подбора в коде уже полностью настроена и заработает автоматически.

4. БАЗА ЗНАНИЙ (ВОПРОС-ОТВЕТ)
----------------------------------------------------------------
Бот обучен на основе официального PDF-регламента компании.
- Базовые и частые вопросы (резервы, акты сверки, пункты выдачи) зашиты напрямую в код (блок FAQ_RULES в app.py) для моментального и бесплатного ответа.
- Сложные и редкие вопросы бот ищет в файле knowledge.txt с помощью нейросети OpenAI.
Если регламенты изменятся, просто обновите текст в файле knowledge.txt.
