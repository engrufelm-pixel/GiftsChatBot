ИНСТРУКЦИЯ ПО ЗАПУСКУ ЧАТ-БОТА GIFTS.RU

1. Окружение:
   Python 3.10+
   Установка библиотек: pip install -r requirements.txt

2. Настройка:
   API-ключи прописаны в файле .env

3. Каталог товаров:
   Товары загружаются из файла catalog.xlsx
   Для обновления базы запустите: python xml_to_excel.py
   (файл product.xml должен лежать в той же папке)

4. Локальный запуск:
   python app.py
   Откройте: http://127.0.0.1:5000

5. Продакшн запуск:
   gunicorn app:app
